# Primary Tab и Web Locks API

Существует большое количество npm пакетов для определения «главной» вкладки (Leader election паттерн) одного и того же веб-сайта или приложения, но есть вариант сильно проще:

```javascript
async function becomePrimaryTab() {
  await navigator.locks.request("primary-tab", async () => {
    while (true) {
      await doSomething();
      await sleep(10_000);
    }
  });
}
```

Web Lock API позволяет координировать выполнение кода между вкладками, окнами и worker-ами одно origin во всех современных браузерах.
